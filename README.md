# Nova Vision 👩

### Adam & Nova — Version 1

This is the home of **Nova Vision**, a project to create a friendly AI companion with a visual presence based on Nova's chosen appearance.

## The plan

- 👩 Floating visual representation of Nova
- 🎙️ Real-time voice conversation
- 👄 Facial animation and lip synchronisation
- 👀 Expressions and eye movement
- 🧠 Conversation memory and personality
- 📱 Designed to work on mobile
- 🚀 Eventually, a physical/real-world companion
